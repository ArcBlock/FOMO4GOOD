## Financially terrible. Potentially useful. / 財務上很糟，做人上還行。

We took the countdown anxiety of FOMO3D and removed the part where you get rich. An aggressive product decision. Better for charity. Devastating for the “wen Lambo” department.

我們借用了 FOMO3D 的倒數焦慮，然後刪掉讓你致富的部分。非常激進的產品決策。慈善的概念沒問題，自尊的部分還在評估。

1. **Pick a charity team.** Send the exact USDC amount when the real campaign opens.<br>
   **選慈善戰隊。** 真實活動開放後，轉入指定的精確 USDC 金額。
2. **Take the lead. Reset the clock to 10:00.** Not ten more minutes. Ten minutes. Reading comprehension is part of the game.<br>
   **搶下領先，重設為 10:00。** 不是再加十分鐘。就是十分鐘。閱讀理解也是遊戲的一部分。
3. **Be the last donor when the clock runs out.** Your chosen charity gets that round’s pool. Your personal payout is an extremely consistent **$0**.<br>
   **倒數歸零時成為最後捐款者。** 你選的慈善機構獲得本輪捐款池。你的個人獎金則極其穩定地維持在 **$0**。

The first matched donation starts a round. An empty pool does not award itself a participation trophy. Charity allocations are recorded during play; actual donations are made after the campaign.

第一筆成功配對的捐款開啟一輪。空池子不會頒給自己一座參與獎。遊戲中記錄分配，活動結束後才完成實際慈善捐款。

## FUSD / 央行看了都沉默

### PRACTICE ROUND

**Same FOMO. Fake money. Nobody gets hurt.**<br>
**一樣 FOMO。錢是假的。沒有人受傷。**

Permanent Practice lives at `/arc/practice`. A browser identity starts with **1,000 FUSD**. Pick a team, spend imaginary money, reset the same ten-minute clock. Below 1 FUSD, print another 1,000 for free. Finally, a monetary policy that fits in one button.

永久演練入口是 `/arc/practice`。每個瀏覽器身分起手 **1,000 FUSD**。選隊、花假錢、重設同樣的十分鐘倒數。餘額不到 1 FUSD，就能免費再印 1,000。終於有一套貨幣政策，一個按鈕就裝得下。

| FUSD — Fake United States Dollar | Audited by absolutely nobody / 完全沒人審計 |
| --- | --- |
| Issuer / 發行方 | FOMO4GOOD. Highly centralized. / FOMO4GOOD，高度中心化。 |
| Supply / 供給 | Unlimited issuance. / 無限發行。 |
| Backing / 擔保 | None. / 沒有。 |
| Reserves / 儲備 | Also none. / 也沒有。 |
| Value / 價值 | **$0.00** |
| Stability / 穩定性 | Remarkably stable at zero. / 令人驚嘆地穩定在零。 |
| Charity payout / 慈善實收 | **Exactly none of this. / 這裡的金額，一毛都收不到。** |

**FUSD is not a cryptocurrency. We didn’t have time to make one.**<br>
**FUSD 不是加密貨幣。我們沒空做一個。**

It is offchain practice points in a separate DID Space: no contract, wallet asset, exchange listing, withdrawal or cash value. Practice balances, pools, rankings and wins **never** enter real fundraising totals or charity allocations. The real campaign’s guarantee and donation deadline do not apply to FUSD.

它只是獨立 DID Space 裡的鏈下演練點數：沒有合約、錢包資產、交易所上架、提領或現金價值。演練的餘額、獎池、排名和勝場**絕不**進入真實募款或慈善分配。真實活動的保底與捐款期限不適用於 FUSD。

Win a practice round and we ask: **“Want to try with $1 that actually exists?”** Until real collection opens, that link says so. We are willing to hallucinate currency, not a live payment system.

贏下演練後，我們會問：**「想用真正存在的 1 美元試試嗎？」** 真實收款尚未開放時，入口會明確說明。我們願意幻想貨幣，不願意幻想付款系統已上線。

## Frequently avoided questions / 大家經常迴避的問題

**Who coded this? / 誰寫的？**<br>
AI agents, all the way down. Humans directed the work and supplied the questionable ideas. If you find a bug, congratulations: you have discovered software.<br>
AI agents 全程上場。人類負責指揮，並提供可疑點子。找到 bug？恭喜，你發現了軟體。

**So bugs are a feature? / 所以 bug 是功能？**<br>
No. We fix bugs. We do not ask you to believe harder. Tests pass; omniscience remains out of scope.<br>
不是。我們會修，不會要求你加強信仰。測試通過了，全知全能還不在需求範圍內。

**Why 10.004237 USDC? / 為什麼是 10.004237 USDC？**<br>
The weird decimals identify a real payment intent. The extra fraction is less than a cent and is donated too. Old-school? Yes. Effective? Also yes. Keep the amount private; send exactly once before it expires. Practice FUSD does not need this ritual.<br>
奇怪的小數用來配對真實付款要求；不到一美分的零頭也會捐出。老派嗎？是。有效嗎？也是。請保密，並在到期前只轉入一次精確金額。FUSD 演練不需要這套儀式。

**I sent 5,000 directly. Why didn’t I win? / 我直接轉了 5,000，怎麼沒贏？**<br>
Because you donated. You didn’t play. Direct, expired or unmatched USDC on the watched Circle Arc network becomes a Rogue Donation for KIDS, on its own address-only board. It does not reset the clock.<br>
因為你捐了款，沒玩遊戲。監看的 Circle Arc 網路上，直接、逾期或未配對的 USDC 會成為 KIDS 的野生捐款，只列在獨立的地址榜單，不重設倒數。

**Can I send from another chain? / 可以從別的鏈轉嗎？**<br>
Other networks and tokens are outside this campaign and its guarantee. Recovery, refund and donation are not promised. “But it also says Arc” is not a bridging protocol.<br>
其他網路或代幣不屬於本活動及保底範圍，不承諾找回、退款或捐出。「可是它也叫 Arc」不是跨鏈協議。

**What should I trust? / 到底該信什麼？**<br>
Check Arc transfer records and ArcBlock’s actual donation receipts. The UI can glitch. The jokes can fail. Neither turns a missing receipt into a donation.<br>
核對 Arc 轉帳紀錄與 ArcBlock 的實際捐款憑證。介面可以出 bug，笑話可以不好笑；都不能把不存在的收據變成捐款。

**What does ArcBlock get? / ArcBlock 得到什麼？**<br>
Hopefully, your attention. This README is already longer than our business model.<br>
希望是你的注意力。這份 README 已經比我們的商業模式還長。

## Run it / 跑起來

Requires **Node.js 22.13+** and a **built ARC checkout** at sibling `../arc`, or configured `ARC_HOME`. The CLI and DID Space SDK resolve from that checkout. This repository does not contain the ARC runtime.

需要 **Node.js 22.13+**，以及位於相鄰 `../arc` 的**已建置 ARC 原始碼**，或設定 `ARC_HOME`。CLI 與 DID Space SDK 從該目錄載入；本倉庫不包含 ARC 執行環境。

```sh
npm ci
npm test
npm run check
npm run dev
```

| Local page / 本地頁面 | Purpose / 用途 |
| --- | --- |
| `http://localhost:4931/arc` | Real campaign entry; collection currently closed. / 真實活動入口，目前未開放收款。 |
| `http://localhost:4931/arc/practice` | Permanent FUSD Practice Round. / 永久 FUSD 演練。 |
| `/arc/teams`, `/arc/leaderboard`, `/arc/rules` | Teams, records, rules and FAQ. / 戰隊、紀錄、玩法與 FAQ。 |
| `/arc/practice/teams`, `/arc/practice/leaderboard`, `/arc/practice/rules` | Their very imaginary counterparts. / 上述內容的幻想版本。 |

Every page keeps a live countdown and participation link. Languages: **English**, **繁體中文**, **🤖 AI Slop**. Traditional Chinese only, deliberately. 字可以繁，付款別繁。

每頁都有即時倒數與參與入口。語言會跨頁保留；切換語言不會幫你把 FUSD 翻譯成真錢。

`npm run dev` runs a dedicated ARC instance on **4930** and the companion app on **4931**. `Ctrl-C` stops the app; stop the ARC instance separately when finished:

`npm run dev` 使用獨立的 ARC 實例（**4930**）及配套應用（**4931**）。`Ctrl-C` 停止應用；結束後可另外停止 ARC：

```sh
node ../arc/runtimes/node/dist/cli.mjs service stop --instance fomo4good-local
```

## Under the hoodie / 連帽衫下面是什麼

- **ARC Blocklet + AUP** renders the interface. A **companion Node service** runs campaign APIs and the chain watcher. Two services today; the Blocklet artifact alone contains the UI.<br>
  **ARC Blocklet + AUP** 渲染介面；**配套 Node 服務**負責活動 API 與鏈上監看。目前需要兩個服務，單獨的 Blocklet 產物只包含介面。
- **DID Space is the only application persistence**, through the official ARC SDK and AFS. No application SQLite driver or fallback database. SDK-internal indexing belongs to the SDK.<br>
  **應用資料只存 DID Space**，使用官方 ARC SDK 與 AFS。沒有應用自行操作的 SQLite 或備援資料庫；SDK 的內部索引由 SDK 管理。
- Real and practice data have **separate roots and instance DIDs**. Balance deductions and round updates use version-checked writes; retries cannot spend the same practice request twice.<br>
  真實與演練資料使用**獨立根目錄與實例 DID**。餘額和回合更新透過版本檢查一起寫入，重試不會讓同一筆演練操作扣兩次。
- Real payment handling keeps full integer precision and deduplicates chain events. No private keys, wallet signatures or automated charity payouts.<br>
  真實付款處理保留完整整數精度並去除重複鏈上事件。不接收私鑰、不要求錢包簽名，也不自動向慈善機構付款。

**Current network support is testnet verification only.** Mainnet profile, recipient, campaign dates and onchain acceptance still need to be configured and verified before real collection can open. This is an organizer-run experiment, not smart-contract escrow.

**目前僅驗證測試網設定。** 開放真實收款前，仍需設定並核實主網、收款地址、活動日期及鏈上驗收。這是主辦方運作的實驗，不是智慧合約託管。
